# Smart Ledger Business Management Services FZE LLC

A professional two-page website for **Smart Ledger Business Management Services FZE LLC**, a UAE-based company offering comprehensive business management, consulting, and support services.

## 🌐 Pages

- **Home** (`index.html`) — Company overview, about section, services highlights, "Why Choose Us", and contact information
- **Services** (`services.html`) — Detailed breakdown of all 10 services with descriptions and feature lists

## 🚀 Deployment

This is a static website — simply serve the files with any web server or deploy to:

- **GitHub Pages** — Push to `gh-pages` branch or enable Pages in repo settings
- **Netlify / Vercel** — Connect repo for automatic deployment
- **Any static host** — Upload `index.html`, `services.html`, `style.css`, and `favicon.svg`
